# Agent avatars

The bots an agent session is drawn as by its role, as zirc-proto's `AGENT_AVATARS` lists them.
They're zirc's own drawings, under zirc's own licence: simple line drawings on a 24 by 24
grid, one stroke weight, in white on nothing, for apps to put on a session's colour.

Made by zirc-theme-art (`src/avatars.rs`): `bazel run //crates/zirc-theme-art`.
